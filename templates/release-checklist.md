# Release checklist: [Release]

## Scope and Decisions

- [ ] Acceptance criteria linked and blocking questions resolved
- [ ] Existing behaviour inspected; no unrelated changes

## Data and Security

- [ ] Migrations/backfill/rollback reviewed
- [ ] Constraints, indexes, RLS and Storage policies tested by role
- [ ] Secrets/config present without exposing values
- [ ] Privacy, retention and audit impacts reviewed

## Quality

- [ ] Unit/integration/end-to-end tests pass
- [ ] Mobile, accessibility, loading/empty/error states checked
- [ ] Notifications/provider failures checked
- [ ] Monitoring and support path ready

## Delivery

- [ ] Non-main branch/PR and required checks
- [ ] Preview/staging smoke test
- [ ] Documentation, manifest and handover updated
- [ ] Rollout and rollback/mitigation agreed
