# Prompt: Competitor analysis

```text
Update the existing Handy Help competitor register using current official sources. For each priority competitor capture official URL, review date, geography, business model, live pricing/fees, customer flow, contractor flow, verification language, matching/contact/payment/review/dispute behaviour, strengths, weaknesses, threat, similarities, differences, copy/avoid lessons and opportunity for Handy Help.

Date all time-sensitive claims, cite evidence and mark unavailable facts. Update existing files rather than creating a new report unless explicitly requested. Do not convert competitor behaviour into a Handy Help requirement without a decision.
```
