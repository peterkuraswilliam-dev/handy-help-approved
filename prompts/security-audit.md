# Prompt: Security audit

```text
Perform a read-only security review of the requested Handy Help surface. Test the documented role/relationship matrix against direct database/API access, not only UI visibility. Review authentication, admin grants, RLS, Storage, server/service-role use, state transitions, IDOR, uploads, XSS, rate limits, contact-protection bypass, notifications/logging leakage, audit integrity and dependency/configuration risks.

Rank findings by impact and likelihood, provide evidence and safe remediation, and distinguish verified findings from hypotheses. Do not change production or weaken protections.
```
