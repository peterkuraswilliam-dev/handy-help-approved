# Marketplace operating model

Status: working proposal.

Purpose: describe how the managed marketplace differs from alternatives.

```text
Customer submits -> local admin verifies -> up to three suitable contractors
-> quotes -> customer selects -> protected coordination -> work lifecycle
-> confirmed completion -> verified review
```

Handy Help should control admission, job quality, match count and platform safety. It should not sell the same lead widely or allow the highest payer to outrank suitability. Operational capacity for review and support must be included in pricing and launch limits.

See [business model](../business/business-model.md) and [differentiation](../competitors/differentiation.md).
