# Opportunity intelligence overview

Status: separate future module.

Purpose: help contractors find likely work opportunities using lawful, relevant public/commercial signals. It is not part of the current onboarding or marketplace MVP.

Potential signals include planning applications, developments/new builds, property attributes, recently sold homes and publicly advertised projects. The module should surface areas/opportunities, not infer sensitive personal circumstances or encourage intrusive direct marketing.

See [Landstack](landstack-and-property-data.md) and [future integrations](future-integrations.md).
