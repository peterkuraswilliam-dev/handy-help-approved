# Opportunity intelligence integrations

Purpose: preserve integration options without committing architecture.

Candidate adapters: planning-data provider, council/open-data feeds, property-sales/licensed dataset, new-build developer feeds, procurement portals and contractor CRM/export.

Every adapter must document licence, attribution, personal-data status, rate limits, provenance, refresh, deletion/correction and failure behaviour. Opportunity signals must never bypass the core distinction between an inferred opportunity and a customer-submitted verified job.
