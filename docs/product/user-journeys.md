# User journeys

Purpose: index the main journeys and their current status.

## Contractor onboarding — current

Owner/admin creates invitation → contractor receives secure link → contractor creates/signs in to own account → start application → add business/services/areas/documents → submit → admin review → request information or decide → contractor responds/resubmits → approve/reject → manage approval/expiry/suspension.

## Customer job — future proposal

Create account → guided job and photos → submit → admin checks → job approved/rejected/information requested → limited matching → quotes → contractor selection → authorised contact/booking → scheduled → in progress → completed → customer confirmation/review.

## Admin — current and future

Review queue → inspect evidence → private checklist/notes → communicate decision → audit history. Future additions include job moderation, match oversight, complaints and Job Rescue.

Detailed flows live in the relevant [feature specifications](../features/README.md).
