# Data retention

Status: policy decisions open.

Purpose: identify records requiring explicit schedules.

Define retention for abandoned drafts, rejected/withdrawn applications, private documents, expired verification evidence, admin notes, jobs/media, messages, payment records, reviews, disputes and audit logs. Consider UK GDPR principles, legal claims, tax/accounting duties and safeguarding needs; obtain appropriate legal advice.

Deletion must distinguish user-visible deactivation, anonymisation, storage object removal, audit/legal holds and backups. Never promise instant erasure where lawful retention applies, and never keep sensitive evidence indefinitely by default.
