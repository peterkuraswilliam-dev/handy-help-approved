# Project overview

Purpose: define the product at a stable, high level.

Handy Help Aberdeenshire is a community-focused service that connects customers with approved local contractors. Unlike an open directory, it is intended to verify jobs, moderate participation, limit matching and provide human support. It should make small and ordinary jobs worthwhile while reducing wasted leads and privacy risks.

## Product layers

1. **Current build — CONFIRMED:** contractor application, admin review, approval and management.
2. **Marketplace — WORKING PROPOSAL:** customers, approved jobs, matching, quotes, booking, lifecycle and reviews.
3. **Opportunity intelligence — FUTURE:** planning/development/property signals for contractors.
