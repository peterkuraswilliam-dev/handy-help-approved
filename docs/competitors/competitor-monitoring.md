# Competitor monitoring

Purpose: define a repeatable evidence process.

Review priority competitors quarterly and before pricing/launch decisions. Use official pricing, terms, help centres and product flows; date every claim and archive a short evidence note. Track: pricing, contractor fees, lead/match limits, verification language, geography, contact release, payments, disputes, reviews and new local entrants.

Monitoring output should update the existing [register](competitor-register.md) and [decision log](../decisions/decision-log.md), not create separate “latest” files. Material competitor changes do not automatically change Handy Help requirements.
