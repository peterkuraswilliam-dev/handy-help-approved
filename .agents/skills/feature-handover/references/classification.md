# Classification reference

- **CONFIRMED:** explicit current instruction or recorded accepted decision.
- **WORKING PROPOSAL:** desired direction or mock-up detail not locked.
- **OPEN QUESTION:** unresolved choice that could change implementation or policy.
- **HISTORICAL:** earlier idea retained for context and possible learning.
- **SUPERSEDED:** earlier decision replaced by a newer confirmed decision.

Visual designs prove that a concept was explored, not that every field, route, price or status is confirmed. Code proves implementation state, not automatically desired product intent. When they differ, record documentation drift and seek resolution.
