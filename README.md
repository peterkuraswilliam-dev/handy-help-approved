# Handy Help Aberdeenshire

Handy Help is a planned managed local matching service for customers and approved contractors across Aberdeenshire. The immediate build focus is invitation-only contractor access, secure onboarding, document review and admin approval; there is no public contractor sign-up. The customer marketplace is documented as staged future scope.

This repository documentation distinguishes confirmed decisions from proposals, open questions and historical concepts. Start with [CODEX_START_HERE.md](CODEX_START_HERE.md); contributors and AI agents must follow [AGENTS.md](AGENTS.md).

## Product promise

- Local human support
- Approved contractors and verified jobs
- Owner/admin invitations for controlled contractor access
- Fair, limited matching rather than bidding wars
- Small jobs welcome
- Privacy and contact protection
- Simple, predictable contractor pricing when monetisation begins
